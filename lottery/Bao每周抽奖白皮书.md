# Bao Weekly Lottery Whitepaper
# Bao每周抽奖白皮书

**English first, then Chinese within each chapter / 每章英文在前，中文在后**

---

## 1. Overview / 概述

**English：**

This is a weekly lottery project based on SHA256 algorithm, implemented on Telegram bot to realize automatic drawing.

**中文：**

这是一个基于SHA256算法的每周抽奖项目，在Telegram机器人上实现自动开奖。

---

## 2. Lottery Principle / 抽奖原理

**English：**

We use SHA256 hash to ensure the randomness and fairness of the draw result, and the result cannot be manipulated in advance.

**中文：**

我们采用SHA256哈希来保证抽奖结果的随机性与公平性，结果无法提前人为操控。

---

## 3. Rules / 规则

**English：**

Eligibility is based on on-chain holding — addresses with market value ≥ **$100** at the weekly snapshot each get one ticket (one person, one vote). The Telegram group is where results are published, **not a sign-up portal**. The system draws winners automatically every week.

**中文：**

参与资格基于**链上持仓**——快照时持仓市值 ≥ **$100** 的地址各获得一张券（一人一票）。Telegram 群是**公布结果的场所**，不是报名入口。系统每周自动抽取中奖者。

---

## 4. Fairness Statement / 公平性声明

**English：**

All draw data is open and verifiable, and anyone can verify the hash result.

**中文：**

全部抽奖数据公开可核验，任何人都可以校验哈希结果。
