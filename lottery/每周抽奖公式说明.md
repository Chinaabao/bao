# 宝($BAO) 每周抽奖公式说明

> 本文件是每周抽奖的核心公式与执行规则，与白皮书一致、与 `scripts/bao_lottery.py` 一一对应。
> 目标是**公平、透明、可复核**：任何人用同样的输入都能算出同样的结果。

## 一、输入（每周一快照时刻确定）

| 变量 | 说明 |
|---|---|
| 合格地址列表 `holders` | 快照时（周一 00:00:00 UTC）持仓市值 ≥ $100 的地址；防女巫机械规则回溯 2 跳，同源整簇合并 = 1 票（一人一票） |
| 种子交易哈希 `tx_hash` | 周一 00:00:00 之后**第一个确认交易**的哈希（slot 锚定，永久可查） |
| 奖池 `prize_sol` | 本期奖池的 SOL 金额 |
| 中奖人数 `n_winners` | 固定 3 |

## 二、公式

1. **排序键**：对每个合格地址计算
   ```
   sort_key = SHA256(地址 + tx_hash)
   ```
   按 sort_key **字典序升序**编号（1..N，N=总票数）。

2. **起始号**：
   ```
   r = int(tx_hash, 16) % N + 1
   ```
   即把种子哈希当作大整数，对总票数取模后 +1，得到第一个中奖号。

3. **抽 3 人**：从第 r 号起**循环取模**依次取 3 个：
   ```
   中奖号 = r, r+1, r+2（对 N 取模，超出回到 1）
   ```

4. **每人金额**：
   ```
   amount_each = prize_sol / n_winners   （保留 6 位小数）
   ```

## 三、公布

- 定下种子哈希的同时，公布 **哈希 + 中奖名单 + 每人金额**（上链留痕 + 社区公示）。
- 复查窗口：公布后 3 天（周一→周四）。纠错**不重抽**，剔除者按排号顺延递补，差额滚入下期。
- 发放：周四由项目方钱包签名，按名单与金额执行（**脚本不转账**）。

## 四、保底与防女巫

- **保底顺延**：奖池 < 1 SOL 时本期不开奖，顺延下期合并。
- **防女巫**：机械回溯 2 跳，同源整簇合并 = 1 票；第 3 跳起不追，默认放行。快照前 30 天窗口可调。

## 五、执行

- 脚本：`python3 lottery/scripts/bao_lottery.py`（读 `lottery/lottery_input.json`）
- 自动化：`.github/workflows/bao-weekly-lottery.yml` 每周一 00:00 UTC 触发，算完自动发电报群
- 手动：`workflow_dispatch` 触发可随时测试

> 全流程公平性：种子来自链上、排序用公开哈希、取模逻辑固定 → 任何第三方都可复现验证，无暗箱。
